# micrograd-from-scratch

A tiny scalar-valued autograd engine and neural net library, built from scratch following Andrej Karpathy’s Zero to Hero series.

This project is based on the following video: [link text](https://youtu.be/VMj-3S1tku0)
The original repo can be found here: [link text](https://github.com/karpathy/micrograd)

## Status
It's currently a work in progress and a learning experience to gain a deeper understanding of backpropagation.

No code in this repo is written by agents, it's a learning exercise.
